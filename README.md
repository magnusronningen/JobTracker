# JobTracker

JobTracker er en fullstack webapplikasjon for å holde oversikt over jobbsøknader.

Prosjektet utvikles som et personlig porteføljeprosjekt, med fokus på å bygge en praktisk applikasjon og samtidig videreutvikle ferdigheter innen fullstackutvikling, API-integrasjon og databaser.

## 🚧 Status

**Under utvikling**

Kjernefunksjonaliteten er på plass, og prosjektet videreutvikles med flere funksjoner og forbedringer.

## ✨ Funksjonalitet

- Opprette jobbsøknader
- Se jobbsøknader
- Redigere jobbsøknader
- Slette jobbsøknader
- Holde oversikt over søknadsstatus
- REST API-integrasjon
- Lagring av data med SQLite

## 🚀 Komme i gang

For å kjøre prosjektet lokalt må både frontend og backend startes.

### Frontend

Åpne en terminal og gå til frontend-mappen:

```bash
cd frontend
npm install
npm run dev
```

### Backend

Åpne en ny terminal og til JobTrackerAPI-mappen:

```bash
cd backend/JobTrackerAPI
dotnet watch run
```

Frontend og backend vil kjøre på adressene som oppgis i terminalene.
